## 五、本次踩到的一个坑（已修复）

首次执行 `npm run deploy-local` 在 `scripts/showcase.ts:160` 抛 `需要平台管理员审核`。
原因：控制库内已存在历史管理员账号（`ruiqi.zhou25@student.xjtlu.edu.cn`），新注册的 `developer@campus.local` 只能拿到 `developer` 角色，而自建模块 `study-waitlist` 的 approve 需要平台管理员。

处理：停机后直接在该控制库把 `developer@campus.local` 提为 `admin`（本机所有者账号，语义正确），重启服务、重跑 `deploy-local`，脚本按其幂等逻辑复用已建项目并完成剩余步骤。
