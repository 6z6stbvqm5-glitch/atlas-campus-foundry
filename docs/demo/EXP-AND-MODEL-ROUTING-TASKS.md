## 一、方向变更说明

演示完成度的要求已下调，考核重心从「现场零故障」转向「有真实数据支撑的对比结论」。因此新增两条工作线：

1. **数据线**：产出三组真实对比数据——纯 AI、AI + 代码库、Atlas 平台三种开发方式在（a）开发耗时、（b）开发成功率、（c）消耗 token 量三个维度上的差异。
2. **能力线**：模型路由（按开发难度自动选档），本次只要求接口与可演示的骨架，主体实现交由他人。

本文档给的是「谁做、做什么、做到什么算完」，不含数据本身。数据必须现场跑出来，不允许估算、不允许编造。

## 二、三组指标的口径（先定死，再动手）

口径不统一，数据必然打架。以下定义写入方案后即冻结，任何人不得中途改。

### 2.1 开发耗时

| 记号 | 含义 | 采集方式 |
| --- | --- | --- |
| `T_wall` | 墙钟时间：需求交付 → 产物通过验收清单 | 计时器 + 录屏时间戳兜底 |
| `T_human` | 人工干预累计分钟：人动手写代码/改配置/查文档的时间 | 手工计时，按段累加 |
| `T_effective` | 有效时间 = `T_wall` − 等人/等网络/等模型重试的时间 | 从 `T_wall` 中扣除记录在案的等待段 |

汇报用 `T_wall` 与 `T_human` 双口径；只报 `T_wall` 会被质疑「靠人硬撑」，只报 `T_effective` 会被质疑「口径自选」。

### 2.2 开发成功率

每轮结果落三档，不落二元：

| 档位 | 判定 |
| --- | --- |
| 一次通过 | 交付后直接通过验收清单，零返工 |
| 修复后通过 | 返工 ≤ 3 轮且总时长 ≤ 单轮上限，最终通过 |
| 失败 | 超 3 轮，或超单轮上限（默认 2h）判定失败，记录卡在哪一条验收项 |

成功率主指标 = 「一次通过率」；辅指标 = 「最终完成率」=（一次通过 + 修复后通过）/ 总轮次。两条都给，避免只挑好看的那条。

### 2.3 token 消耗

| 项 | 口径 |
| --- | --- |
| 计入范围 | 输入 + 输出 token 全计，含工具调用轮次与重试轮次 |
| 纯 AI / AI + 代码库 | 以模型服务商响应中的 `usage` 字段为准，逐轮累加 |
| Atlas 平台 | 以平台 `jobs` 表记录为准（需先完成 M02／M03 埋点） |
| 成本折算 | `cost = tokens_in × price_in + tokens_out × price_out`，单价按**实验当日快照**记录到方案附录 |
| 辅助指标 | 模型调用次数、平均单轮 token、失败轮次 token（失败也烧钱，必须计入） |

### 2.4 控制变量

同一批需求文本、同一模型与版本、同一验收人与验收清单、同一台机器、每个条件每需求重复 3 次、需求执行顺序按固定种子随机化、允许的提示词模板（最多 3 条）预先写定并三臂共用。

## 三、实验设计

- **需求集**：4 个典型校园应用需求 + 1 个边缘案例（预期三臂都吃力，用来防止结论一边倒）。
- **三臂（条件）**：
  - A 臂「纯 AI」：仅对话式模型，无代码库、无平台，从零开始。
  - B 臂「AI + 代码库」：同一模型 + 预先冻结的开源仓库/模板清单（清单三臂共用，引用次数单独记录）。
  - C 臂「Atlas 平台」：需求输入 → 模块组装 → 部署 → 启停，`modelPolicy` 固定为 `fixed:balanced`，确保与 A／B 用同一模型档位。
- **轮次总量**：5 需求 × 3 重复 × 3 臂 = 45 轮（其中 A、B 各 15 轮，C 15 轮）。
- **单轮上限**：2 小时或 3 轮返工，先到者判失败。
- **剔除规则**：网络中断累计 > 10 分钟、机器故障、验收人缺席导致的中断，整轮作废并补一轮；作废原因必须留痕。

## 八、风险与对策

| 风险 | 表现 | 对策 |
| --- | --- | --- |
| 自证偏差 | C 臂由平台团队执行，被质疑「自己人做自己的实验」 | 预注册 + 盲评 + 边缘案例 + 原始数据全公开；执行人写进方案 |
| token 不可比 | A 臂一轮对话很长、C 臂多轮工具调用，总数难直接比 | 同时报 tokens、成本、调用轮数三项；单列失败轮次的浪费 |
| 人工兜底 | A 臂靠人工硬撑把结果拉平 | 单轮 2h／3 轮上限写进方案；`T_human` 单独统计 |
| 单价漂移 | 服务商调价导致成本不可复现 | 单价快照写进方案附录，日期与来源可查 |
| 埋点缺失 | C 臂拿不到 token 数据，实验白跑 | G1 设为硬门：M02／M03／M06 未完成不得开始 C 臂 |
| 样本量小 | 每臂 15 轮，结论易被质疑 | 报置信区间而非单点；结论措辞限定为「在本实验条件下」 |
