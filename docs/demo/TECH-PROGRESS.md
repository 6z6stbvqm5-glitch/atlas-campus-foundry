## 五、边界规则

1. **构建唯一入口**：仅 P1 执行 `npm run build` 与部署；R1 仅执行构建做环境体检；R2 仅在 P1 通知后执行部署。
2. **数据目录独占**：以 `.data` 为唯一演示数据目录；仅 P1 或 R2 执行，R3／R4／R5 不得操作。
3. **非零退出码**：截图并全文上报，禁止自行修改代码、禁止删除 `.data`。
4. **数字口径**：以 `artifacts/reuse-report.json` 为准；汇报材料与之冲突时以该文件为准修改材料。
5. **冻结之后**：仅接受「演示会坏」级别的修复，每次改动记录一行变更日志。
